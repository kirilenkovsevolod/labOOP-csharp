# Лабораторные работы по ООП (C#)

2 курс. Репозиторий с лабораторными работами и отчётами.

| Лаба | Тема | Папка |
|---|---|---|
| ЛР №1 | Выполнение простой программы. Типы данных. Организация ввода и вывода данных (вариант 9) | `Лаб1` |
| ЛР №3 | Вычисление функций с использованием их разложения в степенной ряд (вариант 9) | `Лаб3` |

В каждой папке лабы: исходный код (папки задач / проект) и отчёт (DOCX + PDF).

## Запуск

- **Visual Studio**: открыть проект/решение и запустить (F5);
- **dotnet**: `dotnet run` из папки проекта (для консольных проектов на .NET 9).
